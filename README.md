> **The earliest ancestor of my map engine.** tusa-android is a native Android map renderer written in C++ with OpenGL ES (GLSL shaders), wrapped in a Kotlin app layer. This is where the project began - it later evolved into [TucikMap](https://github.com/artembobkin/TucikMap) (Swift + Metal) and then into [ImmersiveMap](https://github.com/artembobkin/ImmersiveMap), where development now continues.

# tusa-android

A native Android vector map renderer. The rendering core is written in C++ with OpenGL ES and GLSL shaders; Kotlin handles the Android application layer.

It is kept here as a record of the original, hand-written work and the true starting point of the map engine that later became TucikMap and ImmersiveMap.

# tusa-android

A native Android vector map renderer. The rendering core is written in C++ with OpenGL ES and GLSL shaders; Kotlin handles the Android application layer.

It followed the original [TusaAndroid2](https://github.com/Invectys/TusaAndroid2) and later gave way to the Swift + Metal rewrite (TucikMap, then ImmersiveMap). Kept here as a record of the project's evolution.
